# Overview

Sets Hades to 5120x1440 (through interactive mode) by modding the Hex. Seemed reasonable to just use the util since it also fixes the HUD.

# Instructions

Extract to Hades game folder. The _3_ content folders should be under `Hades/`, and the extract folder can be removed.

With _Python 3.10_ (or check for an updated mod, with modern Python support), run the utility from the console in `Hades/` with: `python3.10 -m hephaistos`. Follow the prompts to enable 5120x1440.
